# maschinenlesbar.org

Command-line tools, typed TypeScript clients and Claude Code skills for **open German
public-sector APIs** — parliament and lobbying, official statistics, weather and water levels,
energy, public warnings, jobs and more. Every tool prints clean JSON and has its own website in
English and German.

- **Website:** [maschinenlesbar-org.github.io](https://maschinenlesbar-org.github.io/) · [Deutsch](https://maschinenlesbar-org.github.io/de/) — all tools, filterable
- **Claude Code:** [plugin marketplace](https://maschinenlesbar-org.github.io/plugins/) — `/plugin marketplace add maschinenlesbar-org/plugins`
- **npm:** [@maschinenlesbar.org](https://www.npmjs.com/org/maschinenlesbar.org) — `npm i -g @maschinenlesbar.org/<tool>-cli`

The code is dual-licensed AGPL-3.0-or-later or commercial. The data belongs to the public
bodies behind each API, under their own terms (`DATA_LICENSE.md` in each repository).
